A small update to [Glossa 0.1.0](https://github.com/bropines/glossa/releases/tag/v0.1.0): the AppImage starts on more Linux systems, and the popup can close with a click elsewhere.

## What's new

- **Close the popup with a click elsewhere** (Windows, macOS): *Options → Appearance → Popup → Close on a click elsewhere instead*. The popup, unless pinned, and mouse mode's button close at the first click outside Glossa instead of after a delay. Off by default; mouse mode need not be on. Idea and first version by [@Sergey-git1](https://github.com/Sergey-git1).
- **AppImage on systems without `libxkbcommon-x11`** (a plain Ubuntu 22.04, for one): Glossa left at once there with nothing on the screen. The image now carries the library and uses it where the system has none.
- **A message instead of a silent exit** when no window can be opened (a missing system library, no usable graphics).
- **Windows**: a control API request refused while too many are being answered now gets the whole `503` with its `Retry-After`.

## Upgrading

Install the new version over the old one as the [install guide](https://github.com/bropines/glossa/blob/main/docs/install.md) describes; your settings stay.

## First launch

The builds are not signed yet, so the system asks once:

- **Windows**: SmartScreen → *More info* → *Run anyway*.
- **macOS**: open Glossa once, then *System Settings → Privacy & Security → Open Anyway*. It lives in the menu bar and asks for Accessibility and Screen Recording.
- **Linux**: built and smoke-tested automatically, but not yet run on real hardware. Reports are very welcome.

## Known issues

- Windows on ARM builds have not been run on ARM hardware yet.
- The Intel Mac build running on Apple silicon (Rosetta) reads only Latin text with Apple Vision; use the Apple silicon build there.
- On Wayland, copy and paste into other programs need the desktop's remote-desktop portal (GNOME, KDE).
