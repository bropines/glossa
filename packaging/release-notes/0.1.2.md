A small Linux update to [Glossa 0.1.1](https://github.com/bropines/glossa/releases/tag/v0.1.1).

## What's new

- **The AppImage can update itself**: it now carries its update information, and the release publishes a `.AppImage.zsync` beside it, so [AppImageUpdate](https://github.com/AppImageCommunity/AppImageUpdate) and the AppImage managers built on it replace Glossa with the latest release, downloading only what changed. Updating from 0.1.1 needs this one download by hand.
- **No tray, no alarm**: on a Linux system without an AppIndicator library, Glossa notes once in its log that there is no tray icon and why, instead of logging a crash of its tray thread. It worked without the icon before too.

The portable versions keep their settings in a `data` folder next to the program.

## Upgrading

Install the new version over the old one as the [install guide](https://github.com/bropines/glossa/blob/main/docs/install.md) describes; your settings stay.

## First launch

The builds are not signed yet, so the system asks once:

- **Windows**: SmartScreen → *More info* → *Run anyway*.
- **macOS**: open Glossa once, then *System Settings → Privacy & Security → Open Anyway*. It lives in the menu bar and asks for Accessibility and Screen Recording.
- **Linux**: built and smoke-tested automatically, but not yet run on real hardware. Reports are very welcome.

## Known issues

- Windows on ARM builds have not been run on ARM hardware yet.
- The Intel Mac build running on Apple silicon (Rosetta) reads only Latin text with Apple Vision; use the Apple silicon build there.
- On Wayland, copy and paste into other programs need the desktop's remote-desktop portal (GNOME, KDE).
