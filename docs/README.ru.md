# Документация

Документация Glossa написана по-английски, как принято в проекте. Здесь —
оглавление с кратким описанием каждой страницы по-русски.
[README.md](README.md) — то же оглавление по-английски.

## Пользователю

| страница | о чём |
|---|---|
| [Установка](install.md) | Какой файл скачать; установщик для Windows, образ диска для macOS, `.deb`, AppImage и portable-архивы; первый запуск неподписанной беты, куда ставятся файлы, обновление, удаление; сборка пакетов. |
| [Командная строка](cli.md) | Все команды и флаги `glossa-cli`, вывод `--json`, коды выхода, переменные окружения. |
| [Control API](control-api.md) | Локальный HTTP API (и D-Bus на Linux) запущенного Glossa: эндпоинты, токен, горячие клавиши на Wayland, macOS и через AutoHotkey. |
| [Настройки](configuration.md) | `config.toml` поле за полем, где он лежит, остальные файлы в папке данных, ключи в системном хранилище. |
| [Распознавание текста](ocr.md) | Движки OCR (Google Lens, Windows OCR, OneOCR, Apple Vision, Tesseract, модели с распознаванием изображений, внешние команды) и их настройка; действия OCR, окно результата, копирование в буфер, перевод самим Lens, перевод на месте. |
| [AI-переводчики](ai-endpoints.md) | OpenAI-совместимые эндпоинты: пресеты, настройки, потоковый вывод, решение проблем. |
| [Темы](theming.md) | Файлы тем, светлая и тёмная тема вслед за системой, подложки (Mica, Acrylic), прозрачность, классические темы. |
