## Системные требования

Здесь перечислено только то, что действительно собирается при выпуске.
Других сборок нет.

| | поддерживается | процессоры | состояние |
|---|---|---|---|
| Windows | 10 и 11 (на более старых установщик не запустится) | x86_64; arm64 | На x86_64 автор работает каждый день. Сборку для arm64 на ARM-устройствах ещё не запускали. |
| macOS | 11 и новее на Apple silicon; 10.15 и новее на Intel | arm64; x86_64 | Раннее тестирование, на Apple silicon. Сборка для Intel, запущенная на Apple silicon через Rosetta, распознаёт через Apple Vision только латиницу, поэтому там берите arm64. |
| Linux | Debian 12, Ubuntu 22.04 и дистрибутивы того же возраста или новее, с GTK 3 | x86_64; arm64 | Сборки проходят только автоматическую проверку при выпуске; на настоящем железе их не пробовали. |

32-битных сборок и сборок для Windows 7 и 8 нет.

- **Графика.** Окна по умолчанию рисуются через OpenGL. В *Настройки →
  Внешний вид → Графический движок* можно выбрать видеокарту (Direct3D 12,
  Vulkan или Metal) или программную отрисовку — для машин без рабочего
  видеодрайвера. Минимальная версия OpenGL не измерялась.
- **Библиотеки в Linux.** Системные GTK 3, ALSA и OpenGL. Значку в трее
  нужна библиотека AppIndicator, а в GNOME — ещё и расширение
  *AppIndicator and KStatusNotifierItem Support*. На Wayland часть
  возможностей зависит от порталов рабочего стола
  ([подробнее](troubleshooting.md#linux-и-wayland)).
- **Место на диске.** Файлы версии 0.1.0-beta.2 весят от 8 до 17 МБ
  каждый. Сборка для macOS на Apple silicon занимает 14 МБ (`glossa`) и
  6,5 МБ (`glossa-cli`); размер после установки на других системах не
  измерялся. Веб-движка внутри нет, дополнительные среды выполнения не
  требуются.
- **Место на диске, по желанию.** То, что скачивают модули, заметно
  больше самой программы: управляемый Python — около 25 МБ (65 МБ после
  распаковки) и `uv` — около 15 МБ, модуль PaddleOCR — 30–45 МБ, локальная
  языковая модель — 1,1–1,3 ГБ. Без вашей команды ничего не скачивается.
- **Память.** По данным самого проекта — несколько мегабайт, пока Glossa
  ждёт в трее без открытых окон (через 45 секунд без окон графическая
  часть выгружается), и около 75 МБ с открытыми окнами при отрисовке через
  OpenGL. Для этой страницы цифры заново не измерялись, а в Linux не
  измерялись вовсе.
- **Сеть** для установки и запуска не нужна. Она нужна онлайн-сервисам;
  что и куда отправляется и что работает без сети, описано в
  [«Приватность и данные»](privacy.md).
- **Права администратора** не нужны — кроме установки «для всех
  пользователей» в Windows и установки `.deb` в Linux.

## Какой файл скачать

В каждом [релизе](https://github.com/bropines/glossa/releases) есть такие
файлы (`1.2.3` — номер версии). `x86_64` — обычный компьютер с процессором
Intel или AMD и Mac на Intel; `arm64` — ARM: Mac на Apple silicon, ноутбуки
на Snapdragon, одноплатные компьютеры.

| система | файл | что это |
|---|---|---|
| Windows 10, 11 | `glossa-1.2.3-x86_64-windows-setup.exe`, `glossa-1.2.3-arm64-windows-setup.exe` | установщик |
| | `glossa-1.2.3-x86_64-windows-portable.zip`, `glossa-1.2.3-arm64-windows-portable.zip` | portable-архив |
| macOS 11+, Apple silicon | `glossa-1.2.3-arm64-macos.dmg` | образ диска с `Glossa.app` |
| macOS 10.15+, Intel | `glossa-1.2.3-x86_64-macos.dmg` | то же для Intel |
| | `glossa-1.2.3-*-macos.zip` | `Glossa.app`, `glossa-cli` и документы |
| Debian 12, Ubuntu 22.04 и новее | `glossa_1.2.3_amd64.deb`, `glossa_1.2.3_arm64.deb` | пакет |
| другие дистрибутивы | `glossa-1.2.3-x86_64.AppImage`, `glossa-1.2.3-aarch64.AppImage` | один исполняемый файл |
| | `glossa-1.2.3-x86_64-linux-portable.tar.gz`, `glossa-1.2.3-arm64-linux-portable.tar.gz` | portable-архив |
| | `SHA256SUMS` | контрольные суммы всех файлов |

Файлы `Bropines.Glossa*.yaml` и `glossa.json` — манифесты для winget и
Scoop. В каталоге winget Glossa пока нет, своего бакета Scoop тоже нет,
так что `winget install Bropines.Glossa` её не найдёт; как
воспользоваться манифестами напрямую, написано в
[английской версии](../install.md#winget-and-scoop).

## Windows

### Установщик

Запустите `glossa-…-windows-setup.exe`. По умолчанию программа ставится
только для вашей учётной записи, в `%LOCALAPPDATA%\Programs\Glossa`, и
прав администратора не требует. На первой странице можно выбрать установку
для всех пользователей (в `Program Files`; тогда права понадобятся).

Установщик добавляет Glossa в меню «Пуск», а по желанию — и на рабочий
стол. Флажок *Запускать Glossa при входе в Windows* — тот же
переключатель, что *Настройки → Основные → Запускать вместе с Windows*:
изменить решение можно в любом из двух мест.

Пока релизы не подписаны, SmartScreen может остановить установщик при
первом запуске: *Подробнее → Выполнить в любом случае*.

Glossa работает без прав администратора. Windows не позволяет такой
программе читать или заменять выделенный текст в программе, запущенной от
имени администратора (например, в терминале с повышенными правами). Если
это нужно, запустите от имени администратора и Glossa.

**Обновление.** Запустите установщик новой версии. Работающую Glossa он
закроет сам; настройки сохранятся.

**Удаление.** *Параметры → Приложения → Установленные приложения → Glossa
→ Удалить*. Программа удаления спросит, удалять ли также настройки,
историю и модули; по умолчанию они остаются.

На ноутбуке с ARM берите установщик `arm64`. Вариант `x86_64` там тоже
ставится и работает через эмуляцию, но медленнее.

### Portable-архив

Распакуйте `-portable.zip` куда угодно (хоть на флешку) и запустите
`glossa.exe`. Файл `portable.txt` рядом с программой означает, что
настройки, история и модули хранятся в папке `data` по соседству с
`glossa.exe` и переезжают вместе с ней. Удалите `portable.txt`, если
хотите, чтобы данные лежали в `%APPDATA%\Glossa`, как после установщика.
Для обновления распакуйте новую версию поверх старой; папка `data`
останется.

## macOS

Для Mac на Apple silicon (M1 и новее) берите `arm64`, для Intel —
`x86_64`. Откройте `.dmg` и перетащите `Glossa.app` в «Программы». Glossa
живёт в строке меню: значка в Dock нет, пока не открыто ни одно её окно.

Программа подписана только локальной (ad hoc) подписью и не нотаризована,
поэтому macOS отказывается запускать её в первый раз. В macOS 15 и новее
попробуйте её открыть, затем зайдите в *Системные настройки →
Конфиденциальность и безопасность* и нажмите *Всё равно открыть*. В более
старых системах — щелчок правой кнопкой → *Открыть*. Или в Терминале:

```bash
xattr -dr com.apple.quarantine /Applications/Glossa.app
```

**Разрешения.** *Настройки → Разрешения* в Glossa показывает, что уже
разрешено, и умеет запросить недостающее.

| разрешение | зачем |
|---|---|
| **Универсальный доступ** | читать выделенный текст в других программах, копировать и заменять его: горячие клавиши перевода и режим мыши |
| **Запись экрана** | снимать область экрана для распознавания текста; начинает действовать после перезапуска Glossa |
| **Мониторинг ввода** | режим мыши — только если одного универсального доступа оказалось мало |

Самим горячим клавишам разрешения не нужны.

**Обновление.** Завершите Glossa из строки меню, замените `Glossa.app`
новой версией и выдайте разрешения заново. macOS привязывает их к подписи
программы, а у каждой сборки она своя, поэтому старую запись Glossa в
каждом списке нужно удалить и добавить новую
([как это сделать](troubleshooting.md#разрешения-macos)). Настройки
сохраняются.

**Удаление.** Завершите Glossa и перенесите `Glossa.app` в Корзину.
Настройки останутся в `~/Library/Application Support/Glossa`; остальное
перечислено [ниже](#полное-удаление).

В `.zip` лежит та же программа и вдобавок `glossa-cli` с документами.
Программа для Mac хранит настройки в «Библиотеке» пользователя, а не
рядом с собой; чтобы держать их в другом месте, запускайте её с
переменной `GLOSSA_HOME` (см. [Configuration](../configuration.md)).

## Linux

На настоящем железе сборки ещё не проверялись — о проблемах, пожалуйста,
сообщайте. `x86_64` и `amd64` — для обычных ПК, `arm64` и `aarch64` — для
ARM (Raspberry Pi 4 или 5 с 64-битной системой, ARM-ноутбуки).

### Debian и Ubuntu

```bash
sudo apt install ./glossa_1.2.3_amd64.deb     # или glossa_1.2.3_arm64.deb
```

apt сам подтянет нужное (GTK 3, ALSA, OpenGL) и, если не отключены
рекомендуемые пакеты, Tesseract для распознавания текста без сети и
библиотеку AppIndicator для значка в трее. В GNOME значку нужно ещё
расширение *AppIndicator and KStatusNotifierItem Support* (в Ubuntu оно
есть). Модулям на Python нужен `python3`.

`sudo apt remove glossa` удаляет программу; настройки в `~/.config/glossa`
остаются.

### AppImage

```bash
chmod +x glossa-1.2.3-x86_64.AppImage
./glossa-1.2.3-x86_64.AppImage                             # сама программа
./glossa-1.2.3-x86_64.AppImage cli translate -t ru hello   # glossa-cli
```

Внутри только сама Glossa; GTK 3, ALSA и glibc берутся из системы. Для
запуска нужен FUSE; без него добавьте `--appimage-extract-and-run`. Если
включить запуск при входе в систему, регистрируется сам файл AppImage,
так что после этого не перемещайте его.

### Архив

Распакуйте `-portable.tar.gz` куда угодно и запустите `./glossa`; скрипт
`./install.sh` добавит программу в меню приложений. Нужны те же
библиотеки, что и для AppImage. Как и в Windows, файл `portable.txt`
означает, что настройки лежат в `data/` рядом с программой; удалите его,
чтобы использовать `~/.config/glossa`.

## Где Glossa хранит файлы

| | Windows | macOS | Linux |
|---|---|---|---|
| настройки, история, модули | `%APPDATA%\Glossa` | `~/Library/Application Support/Glossa` | `~/.config/glossa` |
| кэш и журнал | `%LOCALAPPDATA%\Glossa` | `~/Library/Caches/Glossa` | `~/.cache/glossa` |
| файлы, скачанные модулями | `%LOCALAPPDATA%\Glossa` | `~/Library/Application Support/Glossa` | `~/.local/share/glossa` |

Файл `portable` или папка `data` рядом с исполняемым файлом, а также
переменная `GLOSSA_HOME` переносят всё это в одно место.

Ключи API, пароль прокси и токен Lens лежат в файле настроек открытым
текстом, пока вы не выберете системную связку ключей в *Настройки →
Основные → Ключи и приватность* (или в приветственном гиде): Диспетчер
учётных данных Windows, Связка ключей macOS или Secret Service в Linux.
Связка ключей остаётся на компьютере, так что portable-копии на флешке
больше подходит файл.

## Полное удаление

Программы удаления убирают саму Glossa, а ваши данные оставляют, если не
попросить иначе. Чтобы не осталось ничего, сначала отключите запуск при
входе в систему в *Настройки → Основные* (если он включён), завершите
Glossa (значок в трее или строке меню → *Выход*) и затем:

**Windows**

1. *Параметры → Приложения → Установленные приложения → Glossa →
   Удалить*; на вопрос, удалять ли настройки, историю и модули, ответьте
   *Да*. Будут удалены `%APPDATA%\Glossa` и `%LOCALAPPDATA%\Glossa`
   (журнал, кэш и скачанные модулями файлы). «Тихое» удаление
   (`unins000.exe /VERYSILENT`) эти папки не трогает — удалите их
   вручную.
2. Ключи из системной связки: *Панель управления → Диспетчер учётных
   данных → Учётные данные Windows*, записи с именами на `Glossa/`.
3. Portable-копия: удалите её папку. Если запуск при входе остался
   включён, удалите ещё параметр `Glossa` в разделе реестра
   `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` (он же виден в
   диспетчере задач, в автозагрузке).

**macOS**

1. Перенесите `Glossa.app` в Корзину.
2. Удалите `~/Library/Application Support/Glossa` (настройки, история,
   модули и скачанные ими файлы) и `~/Library/Caches/Glossa` (журнал и
   кэш).
3. Если запуск при входе остался включён, удалите
   `~/Library/LaunchAgents/app.glossa.plist`.
4. Ключи: в программе «Связка ключей», в связке «Вход», — объекты со
   службой `Glossa`.
5. Разрешения: уберите Glossa из списков «Универсальный доступ», «Запись
   экрана» и «Мониторинг ввода» в *Системные настройки → Конфиденциальность
   и безопасность* или выполните:

   ```bash
   tccutil reset Accessibility io.github.bropines.glossa
   tccutil reset ScreenCapture io.github.bropines.glossa
   tccutil reset ListenEvent io.github.bropines.glossa
   ```

**Linux**

1. `sudo apt remove glossa` — либо удалите файл AppImage или распакованный
   архив. Если запускали `install.sh` из архива, удалите также
   `~/.local/share/applications/io.github.bropines.Glossa.desktop` и
   `~/.local/share/icons/hicolor/256x256/apps/io.github.bropines.Glossa.png`.
2. Удалите `~/.config/glossa` (настройки, история, модули),
   `~/.cache/glossa` (журнал и кэш) и `~/.local/share/glossa` (скачанные
   модулями файлы).
3. Если запуск при входе остался включён, удалите
   `~/.config/autostart/glossa.desktop`.
4. Ключи: в менеджере паролей рабочего стола (Seahorse, KWallet) — записи
   Glossa.

Копия, запущенная с `GLOSSA_HOME`, хранит всё в указанной папке, а
portable-копия — в `data` рядом с программой. Служб, драйверов и
расширений для браузера Glossa не устанавливает. Программы, с которыми
она лишь взаимодействует (Tesseract, chrome-lens-py, Ollama), ей не
принадлежат и остаются на месте.

## Специальные возможности

Что есть и чего нет:

- **Масштаб.** В *Настройки → Внешний вид* меняются масштаб всего
  интерфейса и, отдельно, размер значков. В *Настройки → Основные*
  задаётся размер текста в окнах, а Ctrl + колесо мыши (или Ctrl с плюсом
  и минусом) над текстом увеличивает только его.
- **Темы.** Светлые и тёмные, при желании — вслед за системой. Темы —
  обычные текстовые файлы, так что цвета можно подобрать под себя
  ([Themes](../theming.md)). Специальной высококонтрастной темы нет.
- **Шрифт.** *Настройки → Основные → Шрифт* — любой из установленных.
- **Клавиатура.** У каждого основного действия есть глобальная горячая
  клавиша, или её можно назначить (*Настройки → Горячие клавиши*); в
  главном окне есть сочетания для перевода, очистки и смены направления.
  Кое-что требует мыши: перетаскивание всплывающего окна и изменение его
  размера, выделение области экрана, полоса сервисов во всплывающем окне,
  которая появляется при наведении указателя. Работа со всеми окнами
  только с клавиатуры не проверялась.
- **Программы экранного доступа не поддерживаются.** Интерфейс Glossa
  нарисован библиотекой egui, а не системными элементами управления, и
  мост для вспомогательных технологий (AccessKit) в сборки не включён.
  Экранный диктор, NVDA, VoiceOver и Orca ничего не смогут прочитать в
  окнах Glossa. Если вы пользуетесь такой программой,
  [`glossa-cli`](../cli.md) делает то же самое — переводит, ищет в
  словарях, распознаёт текст — в терминале.
- **Озвучивание.** Перевод можно прослушать системными голосами
  ([руководство](../guide.md#listening)).

Отзывы от тех, кто пользуется вспомогательными технологиями, очень нужны:
[SUPPORT.md](../../SUPPORT.md).
