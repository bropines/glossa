# Первые шаги

От установки до первого перевода за несколько минут. English:
[getting-started.md](../getting-started.md). Дальше, по задачам, идёт
[руководство пользователя](../guide.md) (на английском).

Glossa пока в стадии беты: под Windows ею пользуются каждый день, версия
для macOS проходит раннее тестирование, а сборки для Linux на настоящем
железе ещё никто не проверял.

Названия пунктов меню и кнопок даны так, как они выглядят в русском
интерфейсе. Язык интерфейса выбирается на первой странице приветственного
гида и в разделе *Настройки → Основные*.

## 1. Установка

Скачайте файл для своей системы со
[страницы релизов](https://github.com/bropines/glossa/releases):

| система | файл |
|---|---|
| Windows 10, 11 | `…-windows-setup.exe` (или `…-windows-portable.zip`, который достаточно распаковать куда угодно) |
| macOS | `.dmg`: `arm64` для Apple silicon, `x86_64` для Intel. Перетащите `Glossa.app` в «Программы» |
| Debian, Ubuntu | `.deb` |
| другие дистрибутивы Linux | `.AppImage` |

Сборки пока не подписаны, поэтому система один раз предупредит:

- **Windows**: в окне SmartScreen нажмите *Подробнее → Выполнить в любом
  случае*.
- **macOS**: попробуйте открыть программу, затем зайдите в *Системные
  настройки → Конфиденциальность и безопасность* и нажмите *Всё равно
  открыть*.

Все файлы, системные требования и подробности — в
[«Установке»](install.md). Если первый запуск не удаётся, загляните в
[«Решение проблем»](troubleshooting.md#программа-не-запускается).

## 2. Первый запуск

Откроется **приветственный гид**. Его страницы:

1. язык интерфейса и тема оформления;
2. *Горячие клавиши* — их можно поменять прямо здесь: щёлкните по
   сочетанию и нажмите новое (Esc отменяет, Backspace очищает);
3. *Как пользоваться*;
4. *Ключи и данные*: где хранить ключи API — в файле настроек или в
   системной связке ключей — и где лежат настройки и история;
5. *Всё готово*.

Кнопка *Пропустить* закрывает гид на любой странице. Открыть его снова
можно в *Настройки → Основные → Показать приветственный гид*.

После этого Glossa живёт в **трее** (Windows, Linux) или в **строке меню**
(macOS). Закрытие окна программу не завершает. В первый раз главное окно
открывается с подсказкой об этом; кнопка *Понятно* убирает её насовсем.

**На macOS** разрешите две вещи, когда система спросит (или в
*Настройки → Разрешения*): **Универсальный доступ**, чтобы читать текст,
выделенный в других программах, и **Запись экрана**, чтобы распознавать
текст с экрана. После выдачи второго разрешения Glossa нужно
перезапустить.

## 3. Первый перевод

Выделите текст в любой программе и нажмите **Ctrl+Shift+Q**.

Рядом с текстом появится всплывающее окно с переводом. Направление Glossa
определяет сама: текст на вашем языке переводится на второй язык, всё
остальное — на ваш. Оба языка задаются в *Настройки → Основные* (*Первый
язык*, *Второй язык*).

Повторное нажатие горячей клавиши закрывает окно; если его не трогать, оно
само скроется через несколько секунд.

| что сделать | клавиши | в Windows |
|---|---|---|
| перевести выделенное во всплывающем окне | Ctrl+Shift+Q | так же |
| открыть главное окно с выделенным текстом | Ctrl+Alt+Q | Win+Alt+Q |
| распознать текст в области экрана | Ctrl+Shift+O | так же |
| распознать и перевести область экрана | Ctrl+Alt+O | Win+Alt+O |
| скопировать текст из области экрана | Ctrl+Alt+C | Win+Alt+C |
| перевести весь экран на месте | Ctrl+Alt+S | Win+Alt+S |

На macOS Ctrl+Alt — это Control+Option. В Windows вместо Ctrl+Alt
используется Win+Alt: сочетание Ctrl+Alt посылает клавиша AltGr, и такие
горячие клавиши «съедали» бы набираемые с ней символы. На Wayland работа
горячих клавиш зависит от рабочего стола
([подробнее](troubleshooting.md#linux-и-wayland)).

Ни учётная запись, ни ключ не нужны: Google, Microsoft, Яндекс, DeepL и
ещё несколько сервисов работают сразу. Переводимый текст при этом
отправляется сервису, который его переводит. Что именно и куда уходит,
описано на странице [«Приватность и данные»](privacy.md).

## 4. Что дальше

- **Всё есть в меню значка в трее**: щёлкните по значку правой кнопкой
  (на macOS — просто щёлкните по значку в строке меню). Там распознавание
  текста, словарь, история, режим мыши и *Настройки*.
- [Руководство пользователя](../guide.md): всплывающее и главное окно,
  словарь, история, чтение текста с экрана, озвучивание, пресеты, режим
  мыши, исключения, горячие клавиши, ИИ-переводчики и модули.
- Подробно о [распознавании текста](../ocr.md),
  [ИИ-переводчиках](../ai-endpoints.md) и [темах](../theming.md).
- Переходите с QTranslate?
  [Сервисы, темы и настройки можно перенести](../../README.md#coming-from-qtranslate)
  (по-английски).
- Что-то не работает — [«Решение проблем»](troubleshooting.md).
